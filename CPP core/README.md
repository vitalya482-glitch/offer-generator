# C++ calculation core

Здесь будет постепенно размещаться C++-ядро расчётов коммерческих предложений.

## Правила структуры

- `Core.h` — головной манифест проекта. В него постепенно добавляются общие библиотеки, определения и центральные элементы логики приложения.
- Каждый класс размещается в отдельной паре файлов внутри `CalcMakerClasses/`:
  - `ClassName.h` — объявление класса;
  - `ClassName.cpp` — реализация класса.
- В `.cpp` сначала подключается собственный `.h`, затем размещаются реализации конструкторов, деструкторов и функций класса.
- Перед каждым элементом класса обязательно ставится комментарий на русском языке.
- Перед каждым полем класса также ставится комментарий на русском языке.
- Внешние библиотеки подключаются только после отдельного согласования и фиксируются в этом README.
- Ядро расчётов не должно зависеть от конкретных Excel-шаблонов. Профили ячеек и адаптер заполнения Excel будут добавлены отдельно.

## Текущие файлы

- `Core.h` — общий манифест, стандартные библиотеки и публичные объявления классов.
- `CalcMakerClasses/` — классы расчётного ядра.
- `CalcMakerClasses/CalcMaker.h` и `CalcMakerClasses/CalcMaker.cpp` — центральный класс расчётов `CalcMaker`.
- `CalcMakerMain.cpp` — консольная точка входа для сборки `CalcMaker.exe`.
- `request.example.txt` — пример входного файла для первого CLI-контракта.

## Локальная сборка

Для Windows используется WinLibs GCC 16.2.0, установленный в:

```text
C:\Tools\winlibs\mingw64\bin
```

Путь к этой папке добавлен в пользовательский `PATH`, поэтому доступны команды `g++` и `cmake`.

## Первый запуск CalcMaker.exe

```text
CalcMaker.exe --self-test
CalcMaker.exe --request request.txt --result result.txt
```

На первом этапе используется простой текстовый контракт без внешних библиотек. Позже его можно заменить на JSON, сохранив входные модели `CalculationRequest` и `CalculationResult`.

## Планируемые компоненты

- `calc_core/` — модели данных, деньги, правила и расчётный движок;
- `calc_cli/` — командный интерфейс для запуска из Python;
- `tests/` — тесты расчётной логики;
- `CMakeLists.txt` — сборка проекта.
